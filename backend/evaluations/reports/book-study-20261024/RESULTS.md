- B 相对 A：已确认成功比例差值 20.0%；任务配对bootstrap 95%区间 [12.0%, 28.5%]；分类聚合敏感性区间 [0.5%, 42.5%]。
- C 相对 B：已确认成功比例差值 9.0%；任务配对bootstrap 95%区间 [3.5%, 15.5%]；分类聚合敏感性区间 [-3.0%, 24.5%]。
- C 相对 A：已确认成功比例差值 29.0%；任务配对bootstrap 95%区间 [20.5%, 38.0%]；分类聚合敏感性区间 [10.0%, 50.0%]。

区间按任务抽样并保留重复记录；分类敏感性使用10个类别整体抽样。任务共享模板，区间的适用范围受到覆盖面的限制。未知状态保持独立，完整计数及识别区间保存在JSON中。多个历史比较仅作探索分析。

## 关闭重新规划

200次C记录中，可验证调用前缀 197 次，录制不完整 3 次。
相同可重放记录中，保留重新规划通过 124 次，关闭重新规划通过 111 次。
重新规划把已确认失败修复为通过 13 次；已确认通过变为失败 0 次；关闭后少执行 45 次模型调用。

比较限定在已录制响应前缀，保留工具重试与相同提示词。没有发出新的模型请求，离线耗时不代表线上延迟，不能据此推算新的线上平均效果。

## 复现

在backend目录运行：

```powershell
venv/Scripts/python.exe -m scripts.book_evaluation analyze evaluations/runs/full-20261023-final --output evaluations/reports/book-study-20261024
venv/Scripts/python.exe -m scripts.book_evaluation run evaluations/runs/full-20261023-final --output evaluations/reports/book-study-20261024/trial
```

run命令调用真实模型，需要backend/.env配置；输出目录必须不存在。analyze完全使用已有真实响应重放。
