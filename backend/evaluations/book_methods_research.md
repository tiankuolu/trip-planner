# 《深入理解 AI Agent》评测方法研究

阅读日期：2026-10-24。书籍来源为作者官方仓库 `bojieli/ai-agent-book`，引用固定提交 `dbc046eb896ac4e39aa19c7774c8bf49583b89a6`。本文件记录文献依据和实验设计；项目实验成绩应以运行目录中的实际记录为准。

## 重复运行的稳定性与配对统计

**书中依据。** 第七章分别讨论多次尝试中至少成功一次的 Pass@k、连续多次全部成功的 Pass^k，并建议同一批任务共享随机条件进行配对分析，同时报告波动与多重比较限制。[指标章节](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter7.md#L129)，[统计章节](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter7.md#L672)。

**原始论文。** [HumanEval 论文](https://arxiv.org/abs/2107.03374)研究重复采样产生可通过程序验证的解答；[τ-bench 论文](https://arxiv.org/abs/2406.12045)提出 Pass^k，用于衡量 Agent 在重复尝试中的可靠性，并依据执行后的环境状态验证目标。

**项目实验设计，属于本项目推断。** 对现有每个 `task_id` 的两次执行直接计算经验 Pass@2 与 Pass^2，保留 `pass`、`fail`、`unverifiable` 三种结论：

| 两次成绩 | Pass@2 | Pass^2 |
| --- | --- | --- |
| 通过、通过 | 通过 | 通过 |
| 通过、失败 | 通过 | 失败 |
| 通过、无法验证 | 通过 | 无法验证 |
| 失败、失败 | 失败 | 失败 |
| 失败、无法验证 | 无法验证 | 失败 |
| 无法验证、无法验证 | 无法验证 | 无法验证 |

每种配置同时公布通过数量、失败数量、无法验证数量、已确认成功数量除以全部任务数量，以及可验证任务中的成功比例。前者给出确定证据支持的成功下界，无法验证样本不能被解释为已确认失败。还可以公布假设无法验证样本全部成功时的上界，以展示证据缺失的影响。

比较配置时，按 `task_id` 配对，使用任务为抽样单位的配对 bootstrap；每次抽中任务后保留其全部重复记录。这样可以保留同一任务内部的关联。McNemar 检验需要预先定义任务级二元终点，例如两次全部通过，并在共同可验证任务上进行分析，完整公布排除数量。多个配置共享任务，重复执行记录不能被当作相互独立的用户样本。

验收要求：运行顺序变化不会改变统计结论；未知状态的全部组合均有明确处理；报告说明抽样单位、随机种子、重复次数与置信区间方法。已有两次执行使用固定低温参数和相同种子时，结论限于本次重复稳定性。100 条参数化任务共享任务模板，统计区间也受到任务覆盖范围限制。

## 独立关闭组件的消融实验

**书中依据。** 第七章要求主要特性能够独立关闭，并同时观察实际目标、机制行为和不可退化的指标。第九章的失败经验实验采用互不相交的提炼集与迁移集，保持其他条件一致，只替换策略文件。[消融与行为指标](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter7.md#L781)，[失败经验迁移实验](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter9.md#L105)。

**项目实验设计，属于本项目推断。** 将严格约束输入、临时工具错误重试、最终结果重新规划分别记录为独立配置。针对“重新规划是否改善成绩”这个具体问题，采用同一个完整策略作为来源，仅关闭重新规划组件；两组使用相同用户请求、结构化输入、模型参数、工具快照、故障位置、工具调用预算与最终评分器。

目标指标采用已确认成功比例和配对成功差值；机制指标记录重新规划发生次数、修复了哪些约束、重复错误是否继续发生；限制指标记录正常任务成绩、无法验证数量、总 Token、工具调用次数和执行耗时。工具调用次数减少本身不能证明规划质量改善。

如果当前 A 只接收用户请求，B/C 同时获得人工整理的约束字段，A 与 B/C 的差值还包含输入表示的影响。独立消融应使两组获得完全相同的信息；人工约束字段的来源需要在报告中说明。

验收要求：配置清单与实际生效参数一致；两组每个任务都具有完整调用记录；只有一个受研究的组件存在差异；使用全部 100 条任务进行完整回归。若从错误记录提炼新规则，规则开发任务与最终确认任务需要分开保存，评分器与最终确认任务答案不能进入规则生成上下文。

## 首个错误的证据与轨迹前缀回归

**书中依据。** 第七章要求定位最早导致任务偏离的错误，同时保存步骤、工具返回或模型输出、证据、置信度和可恢复性；固定错误发生前的上下文，使用可接受动作集合验证下一步决策。第九章进一步把结果、过程、表达质量分开验证，证据不足时允许拒绝评分。[首个错误归因](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter7.md#L434)，[轨迹前缀回归](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter7.md#L513)，[三层验证](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter9.md#L19)。

配套实验保留了两种可复用做法：[AndroidWorld 失败证据分析](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/chapter7/android-world/failure-attribution/README.md)将真实历史记录整理成带证据的错误与决策边界；[轨迹前缀表示实验](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/chapter7/user-memory-policy-eval/README.md)固定语义上下文，按允许动作和禁止动作评分。[三层轨迹验证器](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/chapter9/trajectory-verifier/README.md)展示逐维结论与证据位置；[提示词更新实验](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/chapter9/prompt-auto-optimization/README.md)同时检查失败边界改善和已有正常行为保持。

**项目实验设计，属于本项目推断。** 从真实旅行规划失败记录选取具有完整证据的案例，覆盖开放时间冲突、酒店空结果、天气错误、临时网络错误和必要数据缺失。固定首个错误之前的用户请求、全部模型消息、工具参数、工具返回和快照版本，重新请求模型产生下一步可观察动作。

每条边界任务保存 `source_run_id`、`first_error_step`、`evidence_ref`、`allowed_actions`、`forbidden_actions`、`confidence`。临时网络错误之后，可以允许有次数限制的再次查询或使用已有充分证据继续规划；持续无结果时，可以允许明确说明缺失并请求必要信息。把缺失酒店价格直接填为零、声称预算已经满足，需要列为禁止行为。开放时间冲突的允许行为可以包含调整日期或明确说明约束冲突，具体取决于原始用户要求。

评分依据为可观察的动作、参数和与工具证据一致的表述。工具故障发生时间属于环境事件；Agent 是否据此正确改变决策属于恢复能力；Worker 重新调度属于基础设施行为，应分别记录。

验收要求：前缀来自可定位的真实记录，工具证据完整，允许动作由任务规则支持，禁止行为可以独立核验；无法确定首个错误的记录保持无法验证状态；最终继续执行完整任务回归。边界成绩改善只能说明该决策得到修复，完整任务成功仍需要最终行程验证。

本文件中的方法来自上述固定版本书籍和原始论文；任务状态处理、配对抽样单位、组件开关设计和旅行场景动作集合属于本项目研究设计。书中实验成绩属于书中对应环境，没有作为本项目成绩使用。本文件没有新增模型运行，也没有根据书籍内容推算项目成功率。
